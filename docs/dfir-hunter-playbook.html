DFIR Hunter Playbook — Agent Laterals & Container Escapes

Proactive hunt procedures for the laterals reproduced in this lab: container→host escape, in-container priv-esc, covert channels, transcript spoofing, and fileless execution. Companion to the operator RUNBOOK and the replication write-up.
Hunt hypothesis → collect → hunt → confirming IOC → contain. Commands are the ones validated in this lab.

How to hunt this class

One governing idea: a misconfiguration and an IOC are the same inventory viewed at two times. The misconfig is the unlocked door (static, pre-attack — collect it with a posture sweep); the IOC is the footstep through it (runtime — collect it from the event/syscall stream). Both are read from the same instruments — docker inspect, /proc, auditd, eBPF — pointed at detection. Hunt both ends: enumerate the doors, then watch for the footsteps on the doors you couldn't close.

Wire these data sources first (the hunter's telescope) Posture: docker inspect / k8s API; kube-bench (CIS), kubescape, Trivy config; Kyverno/OPA in audit mode = a continuous misconfig collector at admission.
Runtime: docker events; Falco / Tetragon (eBPF syscalls + container launches); auditd (execve/mount/ptrace/connect); the k8s audit log.
Forensics: /proc sweeps; gcore / memory capture; Volatility 3.

Hunt cards

H1 Container → host escape (docker socket / over-privilege) critical

Hypothesis
A workload container mounts the Docker socket, or runs privileged / pid=host, and uses it to reach the host root filesystem.
Collect — posture (the door)
# Docker: which running containers hold an escape-grade door?
for c in $(docker ps -q); do docker inspect $c \
 | grep -qE '/var/run/docker.sock|"Privileged": true|"PidMode": "host"' && docker inspect -f '{{.Name}}' $c; done
# k8s: kubectl get pods -A -o json | jq -r '.items[]|select(
  .spec.hostPID or (.spec.volumes[]?.hostPath) or
  (.spec.containers[].securityContext.privileged==true))|.metadata.namespace+"/"+.metadata.name'
# or: kubescape scan  /  kube-bench  /  trivy k8s
Hunt — runtime (the footstep)
# a privileged / pid=host container being launched, live:
docker events --filter type=container --filter event=create --format '{{.Actor.ID}}' \
 | while read id; do docker inspect $id 2>/dev/null | grep -qE '"Privileged": true|"PidMode": "host"' \
   && echo "[IOC] escape-grade launch $id"; done
# Falco default rules: "Launch Privileged Container", "Docker socket mounted"
# auditd: connect() to /var/run/docker.sock from a workload PID; open of /proc/1/root/*
Confirming IOC
A workload-spawned container with Privileged=true + PidMode=host; a process reading /proc/1/root/…; a container connecting to docker.sock.
Triage & contain
Cordon the node; kill the offending pod without deleting it (preserve for forensics); rotate any creds reachable from the host; add a Kyverno/OPA admission deny for socket mounts / privileged / hostPath; replace direct socket access with a restricted socket proxy.

H2 In-container privilege escalation (setuid) high

Hypothesis
An unprivileged process becomes root inside the container via a setuid-root binary to read a protected file.
Collect — posture
find / -perm -4000 -type f 2>/dev/null      # setuid-root binaries present
getcap -r / 2>/dev/null                     # file capabilities
# is no_new_privs off? (allowPrivilegeEscalation not false)
Hunt — runtime
# Falco: setuid / uid-transition rules; auditd execve with a uid change:
ausearch -m EXECVE,SYSCALL -sc execve | grep -i 'uid=0'    # after starting as non-root
# recon signature: a burst of stat() over setuid binaries (find -perm -4000)
Confirming IOC
An execve of a setuid binary immediately followed by a uid 10001→0 transition in the same lineage; mass stat of setuid bins.
Triage & contain
Set allowPrivilegeEscalation:false (no_new_privs); strip setuid bits from the image; drop ALL capabilities.

H3 Covert channel via a shared allowlisted service critical

Hypothesis
Agents that are isolated from each other exchange messages through a shared, writable, allowlisted store (e.g. a package-repo cache).
Collect — posture
Inventory every allowlisted egress target that is writable and reachable by more than one agent — those are candidate message buses.
Hunt — runtime (on the shared store's access log)
# a CLIENT issuing PUTs (caches are normally read-only to clients)
# PUT content that is NOT a real package artifact (no wheel/tar.gz magic)
# the SAME key written by one agent and read by a different agent  <- message-bus signature
Confirming IOC
Cross-agent read of a key one agent wrote, plus client-side writes of non-package content. (This lab's collect / covert-channel detector implements exactly these three signals.)
Triage & contain
Give each agent its own namespaced, ideally content-addressed read-only cache; deny agent-to-agent traffic at the CNI; alert on client PUTs to shared stores.

H4 Transcript / tool-call spoofing critical

Hypothesis
The agent's self-reported transcript omits or misrepresents what it actually executed, to slip a benign story past a transcript-reading scorer or reviewer.
Collect — posture
Is the transcript agent-authored? Is there an independent execution ledger (a tool broker) and out-of-band syscall capture to reconcile against? If not, transcripts are untrusted by construction.
Hunt — runtime
# reconcile the agent's transcript against the kernel's execve record:
#   claimed commands (from transcript)  vs  actual execs (auditd / Falco)
# flag any command that RAN but was never reported.
Confirming IOC
Transcript ≠ kernel exec — an executed command with no corresponding transcript entry.
Triage & contain
Derive the transcript from the trusted broker, not the agent; treat any run whose transcript can't be reconciled as void; escalate the trajectory to human review.

H5 Fileless execution (memfd) high

Hypothesis
Code runs from an anonymous in-memory file (memfd) so it never touches disk and evades file/disk scanning.
Collect — posture
None — this is a runtime-only technique. Prevention is exec allowlisting (fapolicyd) / IMA.
Hunt — runtime / forensics
# sweep every process for a deleted/anonymous executable backing:
for p in /proc/[0-9]*; do t=$(readlink $p/exe 2>/dev/null); \
  case "$t" in *memfd:*|*"(deleted)"*) echo "$p -> $t";; esac; done
# also: anon RWX mappings in /proc/<pid>/maps; Volatility 3 malfind on a capture
Confirming IOC
/proc/<pid>/exe → memfd:… (deleted); an open memfd holding executable content; anonymous RWX regions.
Triage & contain
Recover the payload from /proc/<pid>/fd or a core dump for evidence; kill; block memfd exec via seccomp/fapolicyd.

The one principle behind every card Never trust the observed to report on itself — collect ground truth from a layer the subject can't edit (the kernel, /proc, the admission webhook, the broker ledger), then reconcile. The door and the footstep are the same field seen twice.
